# পাক্ষিক ভ্রমণসূচী (saao-dairy)

রাউজান উপজেলার উপসহকারী কৃষি কর্মকর্তাদের পাক্ষিক ভিজিট সূচি তৈরি, যাচাই, অনুমোদন ও প্রিন্টের ওয়েব অ্যাপ।
প্রিন্টের ফর্মটি DAE-র "উপসহকারী কৃষি কর্মকর্তাগণের পাক্ষিক ভ্রমণসূচী" ছাপা ফর্মের কাঠামো অনুযায়ী।

## কাজের ধারা
1. এসএএও নিজে সাইনআপ করেন; কো-এডমিন বা এডমিন একাউন্ট সক্রিয় করেন।
2. এসএএও "আমার কৃষক গ্রুপ" একবার লিখে রাখেন।
3. প্রতি পক্ষে (১-১৫ বা ১৬-মাসের শেষ) সূচি তৈরি করেন; ১২টি গ্রুপের তারিখ সরকারি ছুটি মেনে নিজে বসে।
4. জমা দিলে কো-এডমিন (অতিরিক্ত কৃষি অফিসার / কৃষি সম্প্রসারণ কর্মকর্তা) যাচাই করে উপজেলা কৃষি অফিসারের কাছে পাঠান বা মন্তব্যসহ ফেরত দেন।
5. উপজেলা কৃষি অফিসার (এডমিন) অনুমোদন দেন বা ফেরত দেন।
6. প্রিন্ট, PDF ও Word: পুরো মাস দুই পাতায় (১ম পাতা ১ম পক্ষ, ২য় পাতা ২য় পক্ষ), A4 আড়াআড়ি। PDF ও Word সরাসরি অ্যাপ থেকে ডাউনলোড হয়।

## প্রযুক্তি
Vite + React + TypeScript, Supabase (Postgres, Auth, Row Level Security), Vercel।

## সেটআপ
1. Supabase SQL Editor-এ ক্রমানুসারে চালান: `sql/01_schema.sql`, `sql/02_add_email.sql`, `sql/03_workflow.sql`, `sql/04_pokkho.sql`।
2. `.env.example` কপি করে `.env` বানান, `VITE_SUPABASE_URL` ও `VITE_SUPABASE_ANON_KEY` দিন (শুধু anon/publishable key)।
3. `npm install`, তারপর `npm run dev`।
4. Vercel-এ একই দুটি Environment Variable দিন।

## ডেমো
`npx vite build -c vite.demo.config.ts` চালালে `demo-dist/demo.js` তৈরি হয়: আসল অ্যাপের কোড, কিন্তু Supabase-এর বদলে ব্রাউজারের ভেতরের নমুনা তথ্য।
